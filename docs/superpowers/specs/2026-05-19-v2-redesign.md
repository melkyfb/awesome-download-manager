# Awesome Download Manager V2 — Redesign Spec

**Date:** 2026-05-19  
**Status:** Approved  
**Scope:** Full frontend redesign (desktop + Android) using MUI v6. Backend, Redux store, i18n, and Tauri invoke calls are unchanged.

---

## 1. Goals

- Replace the ported desktop UI with a modern, app-first design that works natively on Android and desktop.
- Adopt Material Design 3 principles: proper touch targets (≥48dp), familiar Android patterns, coherent color system.
- Replace the 35+ legacy CSS-variable themes with 10 curated MUI themes built from scratch.
- Keep a single codebase (Tauri + React). No React Native, no Flutter.

---

## 2. What Changes vs. What Stays

### Changes
| Area | Before | After |
|------|--------|-------|
| Component library | Raw divs + inline styles | MUI v6 components |
| Theme system | 35+ CSS-variable themes | 10 MUI `createTheme()` themes |
| Font provider | Custom `FontProvider` | MUI `CssBaseline` + `@fontsource` (4 font options: Inter, Roboto, Nunito, Fira Sans; `fontId` in `appearance` slice preserved) |
| Layout | Single screen, modals | Drawer navigation + routed screens |
| Add Download | Full-screen modal | Bottom Sheet (mobile) / Dialog (desktop) |
| Settings | Full-screen overlay | Dedicated screen via drawer |
| Button tap targets | ~10dp text-only | 36×36dp icon buttons (mobile) |
| Background | Glass morphism gradient | MUI `background.default` from theme |

### Unchanged
- Redux store: `downloads`, `config`, `ui`, `appearance` slices — all actions and selectors
- All `invoke()` calls to the Rust backend
- `useTauriEvents`, `useForegroundService`, `useUpdateCheck` hooks
- `i18n.ts` and all 10 locale files (`pt`, `en`, `es`, `fr`, `zh`, `hi`, `ar`, `ru`, `bn`, `id`)
- Tauri Android build pipeline (`gen/android/`, `release-android.yml`)
- RTL support for Arabic (`dir="rtl"` on `<html>`)

## 3. Architecture

### MUI Integration

```
src/
  main.tsx              — wraps app in MUI ThemeProvider + CssBaseline
  themes/
    index.ts            — exports THEMES[] (MUI Theme objects, replaces old CSS-var system)
    cosmos.ts           — createTheme({ palette: { mode:'dark', primary:'#BB86FC', ... } })
    obsidian.ts
    carbon.ts
    ocean.ts
    ember.ts
    forest.ts
    arctic.ts
    sand.ts
    synthwave.ts
    royal.ts
  App.tsx               — layout shell: determines drawer variant by breakpoint
  components/
    layout/
      AppShell.tsx      — MUI Drawer (permanent ≥768px, temporary <768px) + main content area
      TopBar.tsx        — MUI AppBar with hamburger (mobile) or title+actions (desktop)
      DrawerContent.tsx — nav items list, speed widget, version
    downloads/
      DownloadList.tsx  — replaces current App.tsx list rendering
      DownloadCard.tsx  — rewritten with MUI Card, LinearProgress, IconButton
      DownloadCardExpanded.tsx — rewritten
      FilterChips.tsx   — MUI Chip group for Todos/Ativos/Pausados/Concluídos
    add/
      AddDownloadFAB.tsx        — MUI Fab (mobile only)
      AddDownloadButton.tsx     — MUI Button (desktop top bar)
      AddDownloadSheet.tsx      — MUI SwipeableDrawer anchor="bottom" (mobile)
      AddDownloadDialog.tsx     — MUI Dialog (desktop)
      AddDownloadForm.tsx       — shared form fields used by both sheet and dialog
    settings/
      SettingsScreen.tsx        — full settings page, replaces old overlay
      SettingsSectionGeneral.tsx
      SettingsSectionDownload.tsx
      SettingsSectionAppearance.tsx
      SettingsSectionAI.tsx
    common/
      GlobalSpeedWidget.tsx     — speed + limit, lives in sidebar on desktop, top area on mobile
```

### Responsive Breakpoint Strategy

```
< 768px  (mobile)  → temporary Drawer (hamburger), FAB, Bottom Sheet for add
≥ 768px  (desktop) → permanent Drawer (sidebar always visible), "+ Novo Download" button in top bar, Dialog for add
```

Implemented via `useMediaQuery(theme.breakpoints.down('md'))` from MUI.

```
│                         │
│  ─────────────────────  │
│  ℹ  v2.0.0              │
└─────────────────────────┘
```

### Main Screen (Downloads)
- Top bar: title "Downloads" + search icon + overflow menu (mobile) / search bar + "+" button (desktop)
- Filter chips below top bar: **Todos · Ativos · Pausados · Concluídos** — filters list in-place
- Scrollable list of `DownloadCard` components
- FAB (mobile only) bottom-right, `borderRadius: 16px`, accent color

### Histórico Screen
Not a separate data source — navigating to "Histórico" via the drawer opens the Downloads screen with the **Concluídos** filter pre-selected. No new Redux state or backend calls needed.

### Settings Screen
Opened via drawer. Groups:

| Section | Items |
|---------|-------|
| Geral | Idioma (select), Iniciar com sistema (switch), Minimizar na bandeja (switch), Notificações (switch) |
| Download | Pasta destino (row→picker), Velocidade máxima (row→input), Chunks paralelos (row→stepper), Tentativas de erro (row→stepper), Verificar SHA256 (switch) |
| Aparência | Tema (opens theme picker with color swatches), Fonte (select from @fontsource packages: Inter, Roboto, Nunito, Fira Sans — replaces old FontProvider) |
| IA | Provedor IA (select), API Key (masked input + save/delete), Provedor busca (select), VirusTotal key |

Each section is a MUI `List` inside a `Paper` with `borderRadius: 14px`.

## 5. Components

### DownloadCard

```
┌─────────────────────────────────────────────┐
│ [icon]  filename.ext              [ATIVO]   │
│         5.4 GB · 3 chunks                   │
│ ████████████░░░░░░░░░  62%                  │
│ 4.2 MB/s · ETA 3min        [⏸] [🗑]        │
└─────────────────────────────────────────────┘
```

- File type icon (28×28dp, rounded 8px): derived from extension — `.iso`→💿, `.exe`/`.msi`→⚙️, `.mkv`/`.mp4`→🎬, `.zip`/`.tar`→📦, `.pdf`→📄, others→📁
- Status badge: color-coded pill — purple=ativo, green=completo, red=erro, yellow=pausado, grey=cancelado
- Progress bar: MUI `LinearProgress`, gradient when active, solid when complete
- Action buttons: MUI `IconButton` 36×36dp — pause/resume and delete
- Error state: replaces action buttons with "↺ Tentar novamente" + delete
- Tap anywhere on card to expand `DownloadCardExpanded` (SHA256, chunk speeds, VirusTotal, mirrors)

### AddDownloadForm (shared)
Fields: URL input, destination row (path + "Alterar" button), AI action buttons (Resumo IA / Malware / Mirrors as compact icon+label cards), primary CTA button "⬇ Iniciar Download".

- **Mobile**: wrapped in `SwipeableDrawer anchor="bottom"` with drag handle, `borderRadius: "20px 20px 0 0"`, `maxHeight: "85vh"`, scrollable
- **Desktop**: wrapped in MUI `Dialog` with `maxWidth="sm"`, same form inside

## 6. Theme System

Each theme is a `Theme` object created with MUI's `createTheme()`. The `appearance` Redux slice stores `themeId: string`. `ThemeProvider` in `main.tsx` looks up the active theme and passes it to MUI.

### 10 Curated Themes

| ID | Name | Mode | Primary | Background |
|----|------|------|---------|------------|
| `cosmos` | Cosmos | dark | `#BB86FC` | `#0d0d1a` |
| `obsidian` | Obsidian Night | dark | `#60a5fa` | `#080810` |
| `carbon` | Carbon | dark | `#22d3ee` | `#111111` |
| `ocean` | Ocean Deep | dark | `#2dd4bf` | `#0c1a2e` |
| `ember` | Ember | dark | `#fb923c` | `#1a0a00` |
| `forest` | Forest | dark | `#4ade80` | `#0a1a0a` |
| `arctic` | Arctic | light | `#3b82f6` | `#f0f4ff` |
| `sand` | Sand | light | `#d97706` | `#faf5eb` |
| `synthwave` | Synthwave | dark | `#ec4899` | `#0d001a` |
| `royal` | Royal | dark | `#fbbf24` | `#0a0a1f` |

Each theme defines: `palette.mode`, `palette.primary.main`, `palette.secondary.main`, `palette.background.default`, `palette.background.paper`, `palette.error.main`, plus `shape.borderRadius: 14` and `typography.fontFamily`.

Default theme: `cosmos`.

---

## 8. i18n

No changes to `i18n.ts` or the 10 locale JSON files. New string keys will be added to all locales for new UI labels (filter chip labels, drawer section names, settings section titles). The `appearance` Redux slice `language` field and RTL logic in `App.tsx` are preserved.

---

## 9. Accessibility & Touch

- Minimum tap target: 36×36dp on all interactive elements (MUI default enforces 48dp on most components)
- Safe area: CSS `env(safe-area-inset-*)` applied to bottom sheet and FAB positioning via `sx` prop
- Focus ring: MUI default outline preserved
- Screen reader: MUI components carry ARIA roles by default; `IconButton` gets `aria-label` from i18n keys
- Keyboard: drawer closes on Escape; dialog closes on Escape
