Decisões de UX nesta seção

  • Settings como tela — abre via drawer, não como modal/overlay. Botão Voltar no top bar leva de volta à tela anterior.
  • Seções agrupadas — Geral / Download / Aparência / IA. Cada grupo num card arredondado, estilo iOS/Material You.
  • Toggles nativos MUI Switch — substituem os checkboxes atuais.
  • Add Download = Bottom Sheet — no mobile sobe de baixo (MUI SwipeableDrawer anchor="bottom"). No desktop continua como Dialog centrado.
  • Botões de IA no bottom sheet — cards compactos com ícone + label, sempre visíveis mas desabilitados se sem API key.
  • Seleção de tema — na aba Aparência mostra swatches das paletas como preview rápido.
