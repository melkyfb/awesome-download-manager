System Tray — comportamento ao iniciar

Quando o app é aberto (ex: no login do sistema), como ele deve se comportar?

A

Abre a janela normalmente

Comportamento atual. A janela aparece. O ícone no tray fica disponível como atalho para reabrir/minimizar. O usuário escolhe minimizar manualmente quando quiser.

Fluxo: Start → 🪟 Janela aparece → usuário clica X → pergunta "minimizar ou fechar?"
B

Inicia direto no tray (silencioso)

No startup do sistema, o app sobe direto para a bandeja sem mostrar janela. Ícone aparece na gaveta. Duplo-clique ou menu do tray abre a janela quando quiser.

Fluxo: Start → 🗂 Ícone no tray (silencioso) → clica → 🪟 Janela aparece
C

Configurável nas Settings

Default: abre janela normalmente. Nas configurações, há um toggle "Iniciar minimizado no tray" para quem prefere que o app suba silencioso com o sistema.

Fluxo: Default = A. Com toggle ativo = B.
