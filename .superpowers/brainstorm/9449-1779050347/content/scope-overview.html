Integrações com o Sistema Operacional

Quais dessas 5 integrações são prioridade para esse ciclo?

A

🗂 System Tray

Minimizar para a gaveta de aplicativos. App roda em background, ícone na bandeja com menu rápido (pausar tudo, abrir janela, sair).

Prós

  • App sempre disponível sem ocupar a barra de tarefas
  • Download continua mesmo com a janela fechada

Esforço

  • Médio — tauri-plugin-tray já existe
  • Precisa do diálogo "fechar ou minimizar"
B

❓ Diálogo ao Fechar

Intercepta o X da janela. Se há downloads ativos → pergunta: Minimizar para tray ou Fechar mesmo. Se não há nada ativo → fecha direto.

Prós

  • Evita interrupção acidental de downloads

Esforço

  • Baixo — depende do Tray (A) estar implementado
C

📋 Clipboard Monitor

Detecta quando uma URL de download é copiada (qualquer coisa com extensão conhecida: .zip, .exe, .apk, .iso…) e abre automaticamente o modal de novo download com o link preenchido.

Prós

  • Zero cliques extras — copy → abre pronto

Esforço

  • Médio — polling ou hook nativo no OS
  • Pode gerar falsos positivos em links genéricos
D

🌐 Interceptação de Downloads do Browser

Extensão de browser (Chrome/Firefox) ou protocolo customizado (adm://) que redireciona downloads para o ADM automaticamente. O browser "entrega" o arquivo ao ADM em vez de baixar ele mesmo.

Prós

  • Experiência seamless — clicou em download no browser, ADM assume

Esforço

  • Alto — extensão separada para cada browser + review na Web Store
E

🔄 Auto-Update Real

Atualmente abre apenas a página de releases. Queremos: detectar nova versão → baixar o instalador em background → notificar → ao clicar, lançar o instalador silenciosamente.

Prós

  • Atualização com 1 clique, sem sair do app

Esforço

  • Médio — tauri-plugin-updater com assinatura dos artifacts
  • Requer gerar keypair e configurar CI de signing
